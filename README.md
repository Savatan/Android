# Countries Explorer — финальный проект

Развитие приложения из предыдущих ДЗ (список / деталка / навигация / сеть / Room / реактивный UI сохранены) в персонализированный offline-first mini-product поверх REST Countries API.

- **ФИО:** Беседа Семен Денисович
- **Группа:** Б9123-09.03.03пикд(1)

## Что именно было добавлено

- Поверх API появился собственный локальный слой пользовательских данных: коллекции стран, заметки к странам, история просмотров.
- Локальный offline-first кэш стран в Room с TTL и фоновым обновлением; список и деталка читают данные из кэша, а не напрямую из сети.
- Новые разделы и экраны: Коллекции и экран коллекции, Заметки, История / Recent, Настройки.
- Нижняя навигация между разделами (Countries / Collections / History / Settings).
- DataStore для настроек и предпочтений, Room для пользовательских данных, сущностей и связей.

## Какие новые пользовательские данные появились

Хранятся в Room:

- **Коллекции** (`CollectionEntity`) и **элементы коллекций** (`CollectionItemEntity`) — пользовательские списки стран; между коллекциями и странами реализована связь «многие-ко-многим».
- **Заметки к странам** (`CountryNoteEntity`) — отдельная заметка на страну.
- **История просмотров** (`RecentViewEntity`) — какие страны и когда открывались.
- **Кэш стран** (`CachedCountryEntity`) — локальная копия контента из API.

Хранятся в DataStore (только настройки/предпочтения): тема, регион по умолчанию, авто-обновление и его интервал.

## Какие новые сценарии реализованы

1. **Коллекции (создаёт новую сущность и новую связь).** Пользователь создаёт коллекцию, добавляет и удаляет в неё страны; на экране коллекции видно её состав. Появляются сущности коллекций и связь «многие-ко-многим» между коллекциями и странами.
2. **Заметки к странам.** Пользователь пишет, редактирует и удаляет заметку для конкретной страны; в списке у стран с заметкой отображается индикатор. Заметка переживает обновление кэша.
3. **История просмотров.** Открытие деталки страны автоматически фиксируется в истории; на экране History показывается список недавно просмотренных с возможностью очистки.

Дополнительно сквозным сценарием работает offline-first кэш стран с TTL и фоновой актуализацией.

## Как устроена offline-first часть

- Список и деталка подписаны на Room (`Flow`), то есть UI берёт данные из локального кэша, а не из сети.
- При первом запуске, если кэш пуст, выполняется одно обновление, которое наполняет кэш; дальше приложение работает с локальными данными и без сети.
- Сеть используется только для обновления/синхронизации: `refresh()` мёржит свежие данные в кэш, сохраняя пользовательские заметки и коллекции; актуальность определяется TTL (`isStale`); поля деталки догружаются по необходимости (`ensureDetail`) и кэшируются.
- При наличии данных в кэше отсутствие интернета не делает приложение неработоспособным.

## Где и зачем используется фоновая обработка

- `RefreshCountriesWorker` (`CoroutineWorker`, WorkManager) периодически обновляет кэш стран в фоне с ограничением `NetworkType.CONNECTED`, чтобы офлайн-данные оставались актуальными без действий пользователя.
- Периодическая задача планируется при старте приложения и перепланируется при изменении интервала на экране настроек; также при старте запрашивается немедленное обновление.

## Какие тесты написаны

- **Бизнес-логика:** TTL / `isStale`; коллекции — отсутствие дублей и корректность связей; заметки — обрезка текста, удаление при пустой заметке, удаление; сохранение результатов обновления в кэш.
- **Реактивная / экранная логика:** список собирается из кэша + поиска + региона + заметок; состояние Empty; обновление при пустом кэше на старте; деталка фиксирует историю и отдаёт заметку в состояние.
- **Offline / sync / background:** кэш отдаётся при ошибке сети (offline-first); `ensureDetail` кэширует деталь; `refresh` сохраняет данные; `RefreshCountriesWorker` возвращает success (work-testing); интеграционные тесты Room DAO.

Открыть проект в Android Studio, дождаться Gradle Sync (JDK 17, compileSdk 35, minSdk 24), запустить `app`. Юнит-тесты: `./gradlew testDebugUnitTest`. Инструментальные: `./gradlew connectedDebugAndroidTest`.
